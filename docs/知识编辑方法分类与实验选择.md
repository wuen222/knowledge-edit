# 知识编辑方法分类与实验选择

你的论文目标不是证明某一个编辑方法失败，而是实证连续知识编辑在多个主流范式下都存在不可靠性。因此方法选择应该覆盖“直接改参数”“定位后改参数”“学习一个编辑器”“不直接改原模型参数”这些主要范式。

## 方法分类

| 类别 | 代表方法 | 主实验建议 | 说明 |
|---|---|---:|---|
| 直接微调/约束微调 | FT-L、FT-M、LoRA、AdaLoRA | 是，取 `FT-L` | 朴素参数更新基线，容易产生灾难性扰动，是很好的下界参照。 |
| Locate-then-edit | KN、ROME、MEMIT、PMET、R-ROME、EMMET、AlphaEdit | 是，取 `ROME`、`MEMIT`、`PMET`、`AlphaEdit` | 最贴合“参数扰动 -> 表示漂移 -> 行为退化”的主线。 |
| Meta-learning / Hypernetwork | KE、MEND、MALMEN、InstructEdit | 补充 | 代表性强，但经常需要 editor checkpoint 或额外训练，工程成本更高。 |
| Memory-based / 非参数 / 半参数 | SERAC、IKE、GRACE、MELO、WISE、SCR-LITE | 后续对照，取 `IKE`、`SERAC`、`GRACE` | 用来对照“不直接改原模型参数”时是否避免参数扰动，但仍可能有检索、上下文、scope 或记忆冲突问题。 |
| Lifelong / Continual editing | GRACE、WISE、UltraEdit、SimIE | 第二版补充 | 与连续编辑场景高度相关，但实现依赖和调参成本更高。 |

## 第一版主实验矩阵

建议参数编辑主表放 5 个方法：

- `FT-L`：直接微调基线。
- `ROME`：单事实 locate-then-edit 代表。
- `MEMIT`：多事实/批量 locate-then-edit 代表。
- `PMET`：精细组件级参数编辑代表，重点回答“编辑应该写到哪里、如何更精确地写”。
- `AlphaEdit`：null-space 约束型参数编辑代表，重点回答“如何减少新知识写入对 preserved knowledge 的扰动”。

这个参数编辑矩阵覆盖三类关键范式：

- 直接参数更新。
- 经典定位式参数编辑。
- 更精细或更保守的定位式参数编辑。

论文表述建议写成：“覆盖主流参数编辑范式的代表方法在连续编辑下出现不同程度的行为退化、参数扰动或表示漂移；其中 AlphaEdit 用来检验显式扰动保护是否能缓解这种退化。”不要写成“所有知识编辑方法都不可靠”，因为这需要覆盖更多模型、数据集、编辑规模和方法实现。

## PMET 和 AlphaEdit 是否重复

二者有重叠，但不是重复。

| 方法 | 主要思想 | 更像回答的问题 |
|---|---|---|
| `PMET` | 更精确地区分 MHSA/FFN hidden states，只用 FFN 相关优化结果更新 FFN 权重。 | 编辑应该写到哪里，如何更精确地写？ |
| `AlphaEdit` | 对参数扰动做 null-space projection，尽量不影响 preserved knowledge。 | 写入新知识时，如何减少对旧知识和无关知识的扰动？ |

因此 `PMET` 更偏“精细定位和精确写入”，`AlphaEdit` 更偏“扰动约束和知识保护”。在你的论文里，它们可以形成互补：如果二者都退化，说明更精细或更保守的参数编辑仍无法完全解决连续编辑可靠性；如果 AlphaEdit 明显更稳，则说明你的诊断框架能区分破坏性编辑和保护性编辑的内部机制差异。

## 第二版补充矩阵

如果第一版跑通且时间充足，再补：

- `MEND`：meta-learning/hypernetwork 代表。前提是 EasyEdit 上对应 Llama 配置和 editor checkpoint 可用。
- `WISE` 或 `GRACE`：lifelong editing 代表。用于回应“连续编辑是否已有专门方法缓解崩溃”。
- `IKE`：in-context editing 代表。
- `SERAC`：外部记忆/检索增强反事实模型代表。
- `GRACE`：adaptor/codebook lifelong editing 代表。

`SCR-LITE` 只建议保留为工程 sanity check 或 appendix。它能帮助验证“外部记忆不直接造成参数扰动”这个直觉，但作为自定义轻量基线，主文说服力不如 `IKE/SERAC/GRACE`。

## 为什么不是每类都选很多个

A800 虽然能跑 7B/8B 实验，但连续编辑要在多个检查点上保存行为指标、hidden-state drift、参数扰动和投影图。方法数量翻倍，成本不只是编辑时间翻倍，还包括调 hparams、排错、画图和解释失败样例。

更稳妥的策略是：

1. 第一版覆盖主要范式，每类取 1-3 个代表。
2. 先把证据链跑通：行为退化、参数扰动、表示漂移、相关性分析。
3. 第二版再补 meta-learning 和 lifelong 方法，增强说服力。

## 和论文主线的对应关系

- `FT-L` 如果退化明显，可以说明朴素参数更新会破坏模型。
- `ROME`、`MEMIT` 如果也退化，说明经典定位式编辑在连续修改下仍可能累积扰动。
- `PMET` 可以检验组件级精细编辑是否缓解损伤。
- `AlphaEdit` 可以检验 null-space 扰动约束是否进一步保护 preserved knowledge。
- `IKE/SERAC/GRACE` 不应用来论证参数崩溃，而应用来讨论非直接改权重方法的检索、上下文、scope 或记忆冲突问题。
